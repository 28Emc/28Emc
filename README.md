### [`eTribunal`](https://github.com/28Emc/etribunal-platform)

Proyecto académico y sin fines de lucro inspirado en una aplicación real que anteriormente desarrollé para un cliente.

El proyecto original utilizaba un **backend monolítico desarrollado con NestJS y un frontend desarrollado con React**, y fue desplegado en producción.

Para eTribunal, retomé la idea y el dominio general de la aplicación como punto de partida para explorar una arquitectura más robusta y escalable, evolucionando el enfoque hacia **microservicios y comunicación orientada a eventos**.

El proyecto también representa un espacio práctico para continuar desarrollando mis conocimientos de **React** ([`etribunal-ui`](https://github.com/28Emc/etribunal-ui)), mientras aplico tecnologías y patrones modernos de backend con Java y Spring Boot 
([`eTribunal-platform`](https://github.com/28Emc/etribunal-platform)).

**React · TypeScript · Java · Spring Boot · Microservices · Kafka · PostgreSQL · Docker**

### [`SGCC`](https://github.com/28Emc/sgcc)

Aplicación desarrollada para automatizar la gestión y cálculo de cobros asociados al consumo de servicios compartidos.

El proyecto parte de un problema real y se enfoca en modelar las reglas de negocio, estructurar la información y proporcionar una API para gestionar el dominio de forma más confiable que un proceso basado en hojas de cálculo.

**Angular · Java · Spring Boot · PostgreSQL · Docker**

---

### [`igo-courier-clone`](https://github.com/28Emc/igo-courier-clone)

Proyecto basado en una experiencia real de desarrollo para una plataforma de gestión de entregas mediante delivery.

Durante el proyecto original participé en la **mejora de módulos existentes de la plataforma de gestión de entregas** y en la creación de una **landing page que anteriormente no existía**, desarrollada con Angular 15+.

La versión disponible en este repositorio es una **reinterpretación personal de la landing page utilizando Astro**, con el objetivo de explorar una alternativa más orientada a contenido y rendimiento, mejorando aspectos como **tiempos de respuesta, SEO, carga inicial y experiencia de usuario**.

El proyecto me permite comparar diferentes enfoques de desarrollo frontend y evaluar cuándo un framework como Astro puede resultar más adecuado que una SPA tradicional para sitios principalmente orientados a contenido.

**Astro · TypeScript · Frontend Architecture · SEO · Web Performance**
